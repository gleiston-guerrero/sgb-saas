# Archivos archivados de mediciones

Esta carpeta actúa como índice documental de las corridas y artefactos
históricos que el equipo decidió archivar por higiene del repositorio.

Por política actual en este repositorio: no se reescribe el historial Git
para restaurar hashes eliminados. En su lugar los artefactos antiguos se
pueden mover aquí (o referenciar desde aquí) para dejar claro cuál es el
archivo canónico activo en la raíz de `docs/mediciones/`.

Actualmente los artefactos canónicos se mantienen en su ubicación original
pero este índice lista las colecciones históricas que podrían moverse a
esta carpeta si el equipo lo autoriza.

Ejemplos sugeridos para archivar (pendiente de mover físicamente):

- `docs/mediciones/jacoco/2026-08-25-jacoco-final/`
- `docs/mediciones/jacoco/2026-08-27-jacoco-cierre-final/`
- `docs/mediciones/lighthouse/` (corridas antiguas)

Si quieres que proceda a mover los archivos físicos a esta carpeta, lo
haré en un único commit. Antes de mover, confirmaré que no haya referencias
en los `.tex` que queden rotas; en caso de hallarlas las actualizaré.
